## DESIGN SYSTEM

### Color Palette

| Color | Hex | CSS Variable | Usage |
|-------|-----|--------------|-------|
| Primary Blue | #1976D2 | `--color-primary` | Primary actions, navigation |
| Secondary Purple | #7B1FA2 | `--color-secondary` | Accents, highlights |
| Success Green | #43A047 | `--color-success` | Success states, published |
| Warning Amber | #FB8C00 | `--color-warning` | Draft, pending review |
| Error Red | #E53935 | `--color-error` | Errors, rejected, archived |
| Neutral Gray | #616161 | `--color-text-secondary` | Secondary text |
| Background | #FAFAFA | `--color-bg` | Page background |
| Surface | #FFFFFF | `--color-surface` | Card, panel background |

### Typography

| Element | Font | Size | Weight |
|---------|------|------|--------|
| App Bar Title | Roboto | 20px | 500 |
| Page Title | Roboto | 24px | 500 |
| Section Title | Roboto | 18px | 500 |
| Body Text | Roboto | 14px | 400 |
| Caption | Roboto | 12px | 400 |
| Code | JetBrains Mono | 13px | 400 |

### Spacing

| Scale | Value | Usage |
|-------|-------|-------|
| XS | 4px | Tight gaps |
| SM | 8px | Compact spacing |

```typescript
interface DataTableProps {
  columns: Column[];
  data: Row[];
  sortable?: boolean;
  filterable?: boolean;
  selectable?: boolean;
  pagination?: boolean;
  actions?: Action[];

// Usage Examples:
```

### Status Badge

| Status | Style | Usage |
|--------|-------|-------|
| Published | Green pill with checkmark | Live content, active products, open jobs |
| Draft | Gray pill | Content/products in progress |
| Pending Review | Amber pill with clock | Awaiting approval |
| Scheduled | Blue pill with calendar | Set to publish later |
| Archived | Red pill | Removed from public view |
| Beta | Purple pill | Beta products/features |
