# Executive-dashboard-service - API Documentation

## Base URL
`/api/v1/executive-dashboard-service`

## Authentication
- `X-Tenant-ID` header required
- `Authorization` Bearer token required

## Main Endpoints
- GET / - List all resources
- POST / - Create new resource
- GET /{id} - Get by ID
- PUT /{id} - Update resource
- DELETE /{id} - Delete resource

For full API documentation, see Swagger UI at /swagger-ui.html
