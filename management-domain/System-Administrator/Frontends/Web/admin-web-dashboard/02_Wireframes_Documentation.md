## RESPONSIVE DESIGN

### Breakpoints

| Device | Min Width | Max Width | Layout Adjustments |
|--------|-----------|-----------|-------------------|
| Mobile | 320px | 767px | Single column, bottom navigation, hidden sidebar |
| Tablet | 768px | 1023px | Collapsible sidebar, 2-column cards, stacked tables |
| Desktop | 1024px | 1439px | 3-column dashboard, expandable sidebar |
| Large Desktop | 1440px+ | - | 4-column dashboard, fixed sidebar, full tables |

### Mobile Adaptations

- **Navigation:** Bottom tab bar instead of sidebar
- **Tables:** Horizontal scroll with card view alternative
- **Charts:** Simplified versions, tap for details
- **Modals:** Full-screen overlays
- **Forms:** Single column, stacked inputs

### Tablet Adaptations

- **Navigation:** Collapsible sidebar with hamburger menu
- **Tables:** Swipe actions for row operations
- **Charts:** Medium detail, touch-interactive
- **Cards:** 2-column grid
- **Forms:** 2-column grid where appropriate
