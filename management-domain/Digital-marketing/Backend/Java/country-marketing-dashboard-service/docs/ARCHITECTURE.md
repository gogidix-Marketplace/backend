# Country Marketing Dashboard Service - Architecture Documentation

## Overview

The Country Marketing Dashboard Service provides country-specific marketing dashboards with localized metrics, KPIs, and reporting.

## Service Purpose

1. **Country Dashboards**: Country-specific marketing performance dashboards
2. **Localized Metrics**: Metrics and KPIs tailored to specific countries
3. **Regional Comparison**: Compare performance across countries
4. **Local Currencies**: Financial metrics in local currencies
5. **Compliance**: Country-specific compliance and reporting

## Technology Stack

- **Spring Boot 3.x**: Application framework
- **Spring Data MongoDB**: Data persistence
- **MongoDB**: Document database

## Key Features

- Multi-country support
- Currency conversion
- Localized reporting
- Regional performance comparison
- Country-specific KPIs
