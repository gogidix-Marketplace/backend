# Financial Reporting Service - Business Use Cases

## Primary Use Cases

### 1. Financial Statement Generation
- **Actors**: CFO, Controller, Accountants
- **Description**: Generate GAAP/IFRS compliant financial statements
- **Process**:
  1. User selects report type and date range
  2. Service aggregates data from General Ledger
  3. Report is generated with proper formatting
  4. Report is available for download or viewing

### 2. Period-End Reporting
- **Actors**: Accounting Team
- **Description**: Automate monthly/quarterly/year-end reporting
- **Process**:
  1. Schedules configured for each period end
  2. Reports auto-generated when period closes
  3. Reports distributed to stakeholders
  4. Audit trail maintained

### 3. Multi-Entity Consolidation
- **Actors**: Corporate Finance Team
- **Description**: Combine financial data across subsidiaries
- **Process**:
  1. Select entities to consolidate
  2. Configure intercompany elimination rules
  3. Apply currency conversion
  4. Generate consolidated statements

### 4. Custom Report Creation
- **Actors**: Business Analysts
- **Description**: Create specialized reports for business needs
- **Process**:
  1. Define report template with rows/columns
  2. Add formulas and calculations
  3. Save template for reuse
  4. Generate reports from template

### 5. Regulatory Reporting
- **Actors**: Compliance Team
- **Description**: Generate reports for regulatory bodies
- **Process**:
  1. Select regulatory report type
  2. Provide required data inputs
  3. Generate compliant report
  4. Export in required format
